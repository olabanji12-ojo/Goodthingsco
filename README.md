# Good Things Co. — Homepage Refinement

Premium editorial homepage redesign with cinematic hero animation.

## Stack
- React 18 + TypeScript
- Vite 5
- Tailwind CSS 3
- GSAP + ScrollTrigger
- Lenis (smooth scrolling)

## Quick Start
```bash
npm install
npm run dev
```

## Project Structure
```
src/
  lib/           — GSAP setup, Lenis hook
  components/
    homepage/    — Hero section layers (Background, Curtains, Foreground, Overlay, Content)
  pages/         — Page-level components
public/
  images/
    homepage/hero/   — Layered hero assets
    branding/        — Logo
```
